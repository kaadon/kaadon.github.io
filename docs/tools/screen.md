# GNU Screen 使用文档

> **GNU Screen** 是一款终端多路复用工具，允许在单个终端窗口中运行多个会话，断开连接后程序仍可后台运行，适用于远程服务器运维和长时间任务管理。

## 1. 会话管理 {#session}

### 1.1 创建会话

```bash
# 创建匿名会话
screen

# 创建命名会话（推荐）
screen -S myapp
```

### 1.2 查看与恢复

```bash
# 列出所有会话
screen -ls

# 恢复指定会话
screen -r myapp

# 恢复唯一会话
screen -r

# 先分离再恢复（会话被占用时）
screen -d -r myapp
```

### 1.3 分离与终止

| 操作 | 命令 |
|------|------|
| **分离当前会话** | 快捷键 `Ctrl+a d` 或 `screen -d myapp` |
| **杀死指定会话** | `screen -X -S myapp quit` |
| **清理僵尸会话** | `screen -wipe` |

## 2. 窗口操作 {#window}

> 所有会话内快捷键均以 `Ctrl+a` 为前缀。

| 快捷键 | 说明 |
|------|------|
| `Ctrl+a c` | 新建窗口 |
| `Ctrl+a n` | 切换到下一个窗口 |
| `Ctrl+a p` | 切换到上一个窗口 |
| `Ctrl+a "` | 列出所有窗口，交互式选择 |
| `Ctrl+a A` | 重命名当前窗口 |
| `Ctrl+a k` | 关闭当前窗口 |
| `Ctrl+a ?` | 显示帮助（快捷键列表） |

---

## 3. 分屏操作 {#split}

| 快捷键 | 说明 |
|------|------|
| `Ctrl+a S` | 水平分屏 |
| `Ctrl+a \|` | 垂直分屏 |
| `Ctrl+a Tab` | 切换分屏区域 |
| `Ctrl+a X` | 关闭当前分屏区域 |

分屏后新区域为空白，需按 `Ctrl+a c` 创建窗口或 `Ctrl+a "` 选择已有窗口。

---

## 4. 复制与滚动 {#copy}

| 快捷键 | 说明 |
|------|------|
| `Ctrl+a [` | 进入复制/滚动模式（方向键或 `PgUp`/`PgDn` 翻看历史，`q` 退出） |
| `Ctrl+a ]` | 粘贴复制的内容 |

复制模式下按 `Space` 开始选择，移动光标后再按 `Space` 完成复制。

## 5. 实用技巧 {#tips}

| 场景 | 建议 |
|------|------|
| **命名规范** | 始终使用 `screen -S name` 创建命名会话，便于识别和管理 |
| **日志记录** | `Ctrl+a H` 开启日志记录，输出保存到 `screenlog.N` 文件 |
| **配置文件** | 自定义 `~/.screenrc` 设置默认行为，如状态栏、滚动缓冲区大小 |
| **滚动缓冲** | 在 `~/.screenrc` 中添加 `defscrollback 10000` 增大历史缓冲行数 |
| **状态栏** | 在 `~/.screenrc` 中添加 `hardstatus alwayslastline "%w"` 显示窗口列表 |
| **替代方案** | 如需更现代的功能（如鼠标支持、窗格布局），可考虑 `tmux` |
